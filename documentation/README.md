# Grandline Documentation

Welcome to the Grandline documentation library. This directory contains detailed guides covering the application's architecture, API specifications, database design, and development workflows.

## Documentation Index

- **[System Architecture](ARCHITECTURE.md)**: Deep dive into the monorepo architecture, module boundaries, backend clean architecture, frontend domain models, and security layers.
- **[API Reference](API.md)**: Full REST API specification (`/api/v1/*`) including request/response contracts, authentication flow, error handling (RFC 7807), and route documentation.
- **[Database Guide](DATABASE.md)**: PostgreSQL schema design, entity relationships, tenant isolation, indexing strategies, and EF Core migration procedures.
- **[Development Guide](DEVELOPMENT.md)**: Step-by-step instructions for local development setup, environment variables, seeding demo data, running unit/integration/E2E test suites, and troubleshooting.
